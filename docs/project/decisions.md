| D-13 | 2026-09-15 | Build the minimap (`scenes/minimap.tscn`, `scripts/minimap.gd`) as a static 2D overlay reusing the existing NAIP ground texture as its background, with the player's world position mapped onto it via a linear formula, rather than a live top-down `Camera3D`→`SubViewport` render | The NAIP texture already covers exactly the ground plane's 520m×520m extent 1:1 (D-7), so the world-to-map mapping is a single linear transform, not a rendering pipeline; a live camera would auto-reflect future world changes and could rotate with the player, but costs an extra render pass the static approach doesn't need.
